Riservata per progetto

  • Ogni foto, file, nota e nome di file viene crittografato con AES-256 sul tuo dispositivo prima di essere salvato.
  • Il tuo PIN o la tua password vengono rafforzati con Argon2id. Funzionano Face ID, Touch ID, PIN e password complete.
  • Nessun account, nessuna pubblicità, nessuna statistica, nessun tracciamento. Su App Store c’è scritto “Nessun dato raccolto”.
  • Nessun server, ed è una promessa: Vaulora non caricherà mai la tua cassaforte, anche se l’app dovesse cambiare proprietario.
